# BANCO · BLOQUE 1 — RECUPERACION
#
#     consulta | norma | articulos aceptables | puesto maximo
#
# - "norma": OBLIGATORIA. Desde que hay dos normas cargadas, un numero de
#   articulo por si solo no identifica nada: el "articulo 75" es "Devengo del
#   impuesto" en la Ley y "Supuestos de aplicacion" en el Reglamento. Se
#   admite cualquier nombre que el sistema sepa resolver: "Ley 37/1992",
#   "Ley del IVA", "Reglamento del IVA", "Reglamento del Impuesto".
# - "articulos aceptables": basta con que salga UNO. Sin la palabra "Articulo".
# - "puesto maximo": en que posicion como muy tarde tiene que aparecer.
#
# Anadir casos NO requiere tocar codigo: se anade una linea.
#
# COMO SE ESCRIBE UN CASO (importante, y en este orden):
#   1. se elige un ARTICULO del corpus y se lee su rubrica;
#   2. se escribe la consulta que haria un gestor para llegar a el.
# Nunca al reves. Una consulta copiada de la rubrica se aprueba sola y no
# prueba nada.
#
# REGLA PERMANENTE SOBRE LAS EXPECTATIVAS
#   Una expectativa solo se cambia con EVIDENCIA INDEPENDIENTE de la salida
#   del sistema (la rubrica del articulo, su texto). NUNCA porque el buscador
#   devolvio otra cosa. Cada cambio va con su motivo al lado.
#
# Este bloque NO gasta llamadas al modelo.

# LAS ROJAS NO SON TODAS LA MISMA COSA

# El bloque 1 puentea el analizador A PROPOSITO: mete la consulta cruda en el
# buscador. Por eso sus rojas dicen «el buscador SOLO no llega», que NO es lo
# mismo que «el sistema falla». Hay dos clases, y confundirlas cuesta caro:
#
#   [SISTEMA]  el articulo no sale ni con los terminos del articulado. Aqui hay
#              algo que arreglar en la recuperacion.
#
#   [PUENTE]   sale mal con la pregunta cruda y sale EL PRIMERO con los
#              terminos que propondria el analizador. No hay nada roto: falta
#              el puente de vocabulario, que es justo para lo que existe la
#              llamada 1. El bloque 5 los repite con el analizador de verdad.
#
# Medido el 11/08/2026, con el filtro por impuesto ya puesto:
#
#   art. 80 Ley 37/1992   «un cliente no me paga la factura»        [PUENTE]
#   art. 89 Ley 37/1992   «he repercutido IVA de mas»               [PUENTE]
